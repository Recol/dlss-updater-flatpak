DLSS Updater — Flatpak repository

The update channel for the DLSS Updater Flatpak bundles published on GitHub Releases.

This is an OSTree repository, not a web page — point flatpak at it:

flatpak remote-add --user --if-not-exists \
    dlss-updater https://recol.github.io/dlss-updater-flatpak/dlss-updater.flatpakrepo
flatpak install --user dlss-updater io.github.recol.dlss-updater

Installing a recent .flatpak bundle from the releases page configures this remote for you, after which updates arrive through flatpak update or your desktop software centre.
